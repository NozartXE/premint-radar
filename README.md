Premint is a token launch radar. It fits a value curve on the traded tokens inside one sealed DefiLlama snapshot, prices every protocol that records no token yet from its TVL, its seven-day growth and how long it has run without one, validates the model out of sample, and nets every farm plan — slice if a launch happens, minus fees, forgone yield and your time — to a verdict: worth farming, marginal, or skip.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
